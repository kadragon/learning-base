# Learning Base

HTML presentation materials for explaining developer knowledge to department members.

Each presentation lives in `presentations/<slug>/`. See `docs/runbook.md` for validation and preview commands.

## Presentations

Published with GitHub Pages from `main`; a merge appears within a few minutes.

| Deck | Topic | Link |
|---|---|---|
| `git-basics` | Git, 가지를 만들고 합치는 일 | https://kadragon.github.io/learning-base/presentations/git-basics/ |
| `vue-basics` | Vue, 생태계부터 프레임워크까지 | https://kadragon.github.io/learning-base/presentations/vue-basics/ |
| `llm-wrks-basics` | AI에게 일을 맡기는 법 (LLM · 웍스AI) | https://kadragon.github.io/learning-base/presentations/llm-wrks-basics/ |

Append `#<number>` to open a specific slide, e.g. `…/llm-wrks-basics/#7`.

`llm-wrks-basics` animations respect the OS reduced-motion setting: with Windows "Animation effects"
off, slides show their final frame only. Turn it on under Settings → Accessibility → Visual effects.
