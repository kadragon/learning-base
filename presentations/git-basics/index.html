VS CODE 07 · MERGE BACK

만든 가지를 main에 합치고 정리하기

terminal · git-practice
$ git switch main
Switched to branch 'main'

$ git merge feature/hello
Updating ef8098f..b5f2735
Fast-forward
 README.md | 2 ++
 1 file changed, 2 insertions(+)

$ git branch -d feature/hello
Deleted branch feature/hello (was b5f2735).
  1. 합칠 목적지로 먼저 이동 (git switch main · 상태 표시줄에서 main 선택해도 동일)
  2. 가져올 가지를 지정해 병합 (git merge feature/hello)
  3. Fast-forward = main에 새 커밋이 없어 이름표만 가지 끝으로 이동, 별도 병합 커밋 없음
  4. 다 쓴 가지 정리 (git branch -d feature/hello)

여기까지가 오늘 실습의 축소판 · 첫 커밋 → 가지 생성 → 커밋 → 병합 → 정리를 원격 없이 한 바퀴 돌았습니다

팀 저장소에서는 이 병합을 push → PR → 리뷰를 거쳐 원격에서 합니다 · 다음 슬라이드부터 실제 팀 저장소를 clone해 같은 한 바퀴를 돕니다

GITIGNORE

애초에 추적하지 않을 파일 정해 두기

.gitignore
# 개인 설정 · 비밀 값
.env

# 빌드 결과물
build/

# 로그 · OS가 만든 파일
*.log
.DS_Store
  1. 프로젝트 최상위 폴더에 .gitignore 파일을 만든다
  2. 한 줄에 패턴 하나 (* = 아무 글자, 끝의 / = 폴더)
  3. .gitignore 파일 자체는 커밋해서 팀과 공유한다
  4. 소스 제어 패널의 CHANGES 목록에서 사라지면 적용 완료

비밀번호·토큰처럼 공유하면 안 되는 값, 빌드 결과물처럼 언제든 다시 만들 수 있는 파일은 커밋하지 않습니다

주의 이미 한 번 커밋된 파일은 .gitignore에 적어도 추적이 멈추지 않습니다. 그런 파일을 발견하면 강사에게 알려 주세요.

MERGE EDITOR

VS Code Merge Editor로 충돌 해결하기

INCOMING · main Message: 안전하게 함께 개발하기
CURRENT · feature Message: 즐겁게 함께 개발하기
RESULT · 최종 결과 (직접 편집 가능) Message: 안전하고 즐겁게 함께 개발하기 ✓ conflicts resolved

충돌 해결 흐름: 파일 저장 → Stage 등록 → 결과 확인 → Merge Commit → Push

위 결과는 두 버튼만으로는 나오지 않습니다. Result 영역에 커서를 놓고 직접 입력하거나, Accept Combination으로 양쪽을 합친 뒤 다듬으세요.

READ THE MESSAGE FIRST

자주 만나는 오류 메시지와 대응

화면에 뜨는 메시지무슨 뜻이고, 무엇을 하면 되는가
! [rejected] … (non-fast-forward) 원격에 내가 모르는 커밋이 있음 먼저 git pull 로 받아 합친 뒤 다시 push
Please tell me who you are 커밋 작성자 정보가 없음 git config --global user.name · user.email 설정
Your local changes … would be overwritten by merge 저장만 하고 커밋하지 않은 변경이 있음 그 변경을 먼저 commit 한 뒤 다시 merge
fatal: not a git repository Git 저장소가 아닌 폴더에서 실행함 프로젝트 최상위 폴더를 다시 열기
CONFLICT (content): Merge conflict in … 오류가 아니라, 사람의 선택을 기다리는 정지 Merge Editor로 해결 → Stage → Commit
로그인 창이 반복해서 뜨거나 인증에 실패 서버 계정·토큰 문제 혼자 재시도하지 말고 강사 호출 (자격 증명 재등록 필요)

Git의 오류 메시지는 대부분 다음에 무엇을 하라까지 함께 알려 줍니다. 창을 닫지 말고 끝까지 읽어 보세요.
