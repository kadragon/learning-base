SHARED REPOSITORY, NOT FORKS

OUR DEFAULT

Shared Repository

WHEN NEEDED

Fork Workflow

RECOVERY BEFORE PANIC

실수했을 때의 순서

1git status현재 상태 읽기
2git diff변경 내용 읽기
3git merge --abort미완료 병합 중단
4git revert공유된 커밋을 새 커밋으로 되돌리기
첫 강의의 금지 구역 reset --hard push --force 이미 공유한 역사는 다시 쓰지 않는다
